# 🌐 GlobeTalk AI – Your Smart Language Companion

GlobeTalk AI is an AI-powered language assistant built with Python and Streamlit. It helps users translate languages, improve grammar, understand context, and practise conversations with AI.

## 🚀 Live Demo

[Try GlobeTalk AI](https://globetalk-ai-rakisha.streamlit.app/)

## ✨ Features

- 🌍 **Language Translation** – Translate text between supported languages.
- 🎙️ **Voice Input** – Convert spoken words into text.
- ✍️ **Grammar & Tone** – Improve grammar and adjust writing tone.
- 🧠 **Context Translation** – Translate expressions while preserving their intended meaning.
- 💬 **Conversation Practice** – Practise real-life conversations with an AI partner.
- 📖 **Phrasebook** – Save and revisit useful phrases.
- 🕘 **History** – View previous translation activities.
- 🎨 **Modern UI** – Premium purple-themed interface.

## 🛠️ Tech Stack

- Python
- Streamlit
- Groq AI
- Speech recognition / audio input
- Translation libraries and APIs
- HTML and CSS

## ⚙️ Run Locally

1. Clone the repository:

```bash
git clone https://github.com/rakisha1302/GlobeTalk-AI.git
cd GlobeTalk-AI
```

2. Create and activate a virtual environment:

```bash
python -m venv venv
```

Windows:

```bash
venv\Scripts\activate
```

3. Install dependencies:

```bash
pip install -r requirements.txt
```

4. Configure your API key using Streamlit secrets or your local environment. Never commit real API keys or secret files to GitHub.

5. Start the application:

```bash
streamlit run app.py
```
